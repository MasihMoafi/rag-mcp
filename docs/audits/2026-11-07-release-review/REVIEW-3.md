# Review: rag-mcp `e61a888`

## Verdict

**Not ready to publish.** A successful reconnect can remove an MCP host’s path restriction, and a failed recovery can print credentials. The ignore cache can retain a file after it becomes ignored, while explicit embedding credentials can be silently overridden by a saved key. These are source-level findings; the release and CI outcomes were not checked. [Reconnect](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/cli_agents.py:64), [ignore cache](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:809), [credential resolver](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/settings.py:224).

**Not yet on par with the sampled DeepSeek harness engineering.** rag-mcp now has strict checking for four modules and typed MCP request declarations, but its runtime validator omits an advertised constraint and its response validation generally accepts any JSON object. The reference uses validated protocol models and defines release-shaped checks across more platforms. [rag-mcp typing](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/pyrightconfig.json:2), [MCP validation](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:577), [reference models](/home/masih/Desktop/p/ext/deepseek-harness/python/sdk/src/deepseek_harness/models.py:35), [reference targets](/home/masih/Desktop/p/ext/deepseek-harness/.github/workflows/build-exe-for-python-sdk.yml:103).

## Problems introduced by the fixes, ranked

1. **P1 — Successful reconnect removes restrictions.** The replacement command contains no old environment settings, so an existing `RAG_MCP_ALLOWED_ROOTS` can disappear when replacement succeeds. Preserve the applicable settings on replacement. [cli_agents.py](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/cli_agents.py:143).
2. **P1 — Recovery can disclose credentials.** If restoration fails, the complete old entry is printed to stderr; Claude restoration also puts its JSON, including any environment secrets, in command arguments. Redact diagnostics and avoid putting secrets in arguments. [cli_agents.py](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/cli_agents.py:67), [Claude restore](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/cli_agents.py:189).
3. **P1 — Ignore decisions can stay stale or fail open.** Git’s tracked-file state affects `check-ignore`, but the cache key omits the Git index. A tracked file made untracked while an existing rule ignores it can remain in the cached manifest. Git failures also become cached empty ignore sets. Include index state and do not cache failures. [server.py](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:809), [Git invocation](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:847).
4. **P1 — An explicitly supplied key can be ignored.** Once a dedicated OpenRouter key is saved, it wins over `RAG_MCP_EMBED_API_KEY` and a new `rag setup --api-key`; setup can probe the old key and report success while saving the new one. Honor explicit overrides and probe the key that will be used. [resolver](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/settings.py:224), [setup probe](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/settings.py:381).
5. **P2 — Allowed-root checking has a race.** A file replaced by a symlink after `_normalize_path` passes can be resolved again and read by workspace import without another allowed-root check. Use a no-follow, descriptor-based read. Exploitation was **not checked**. [server.py](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:1233), [workspace_import.py](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/workspace_import.py:38).
6. **P2 — The new validator permits expensive inputs.** `search_workspace.source_ids` has no maximum, and uniqueness checking repeatedly scans list prefixes before dispatch. Cap the input and check string uniqueness in linear time. [schema](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:370), [validator](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:605).
7. **P2 — Advertised schema and validation differ.** `query_knowledge_base` advertises `oneOf` for its two scopes, but the new validator does not evaluate `oneOf`; the model-shape test does not check it. Validate the complete advertised constraint. [schema](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:350), [validator](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/rag/server.py:577), [test](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/tests/integration/test_mcp_invalid_params.py:91).
8. **P2 — Artifact coverage was weakened.** The current smoke forces BM25, checks only that the mock received a model and path during setup, and never performs installed-artifact semantic search. `--skip-fastembed` remains in the runner although the smoke has no FastEmbed run to skip. [smoke](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/tests/install/smoke.sh:17), [mock assertion](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/tests/install/smoke.sh:45), [runner](/home/masih/Desktop/p/.worktrees/rag-mcp-prod/tests/install/run.sh:9).
