## Release blockers, ranked

1. **P1 — OpenRouter key can overwrite and be sent to another provider.** `rag key set` stores the key in the shared embedding-key field while retaining an existing non-OpenRouter endpoint. The embedding client then uses that key for the other endpoint; OpenRouter synthesis does not accept it as its saved key. `remove` clears the same shared field, and validation occurs after saving. Confirmed with in-memory mocks. [rag/keys.py:76](../../../rag/keys.py:76), [rag/embeddings.py:348](../../../rag/embeddings.py:348), [rag/openrouter_pipeline.py:81](../../../rag/openrouter_pipeline.py:81)

2. **P1 — Reconnecting can lose an existing MCP registration.** Codex and other connection paths remove `rag` before adding the replacement. If the add fails, the old registration is already gone. The Codex sequence was confirmed with mocked subprocesses. [rag/cli_agents.py:51](../../../rag/cli_agents.py:51), [rag/cli_agents.py:96](../../../rag/cli_agents.py:96)

3. **P1 — Changed ignore rules can leave files in a long-running server’s scope.** The scope manifest and per-directory Git-ignore results are cached. Editing ignore rules does not itself invalidate the cached manifest; an in-memory reproduction retained a newly ignored file on the next scan. This can expose stale selected content to retrieval or a configured provider. [rag/server.py:518](../../../rag/server.py:518), [rag/server.py:585](../../../rag/server.py:585)

4. **P1 — A clean checkout cannot build the intended Studio-free distribution.** Both distributions force-include the Studio archive, the hook rejects its absence, and the archive is Git-ignored. A local archive is present and passed its manifest check; that does not make it available to a fresh checkout or justify shipping it. Decouple the build and make the Studio command’s unavailable status clear. [pyproject.toml:67](../../../pyproject.toml:67), [hatch_build.py:15](../../../hatch_build.py:15), [.gitignore:13](../../../.gitignore:13)

5. **P1 — Define and verify the MCP trust boundary.** `RAG_MCP_WORKSPACE_ROOT` resolves relative paths; it does not confine absolute paths or `..`. An explicitly named file bypasses the directory’s hidden-file, Git-ignore and scan-budget filters. A caller with the stdio connection can therefore select supported files readable by the process; source import can subsequently expose requested chunks. State that clients are trusted, or enforce an approved-root/host-authorization policy where confinement is required. [rag/server.py:495](../../../rag/server.py:495), [rag/server.py:567](../../../rag/server.py:567), [rag/workspace_import.py:36](../../../rag/workspace_import.py:36)

6. **P1 — Make network behavior enforceable and clear.** FastEmbed temporarily removes even explicitly set Hugging Face offline variables while loading a model. Separately, an available OpenRouter key enables hosted reranking by default unless overridden; answer synthesis sends selected evidence to OpenRouter. Respect an explicit offline setting and disclose these behaviors in the npm-facing instructions. [rag/embeddings.py:82](../../../rag/embeddings.py:82), [rag/settings.py:215](../../../rag/settings.py:215), [rag/openrouter_pipeline.py:243](../../../rag/openrouter_pipeline.py:243)

7. **P1 — Prove prompt-injection handling before claiming it.** The answer prompt tells the model that passages are untrusted, but ordinary generated answers are returned after completion checks; requested workspace chunks can also return document text to the host. The contextual-enrichment prompt includes document text as user content. An actual injection exploit was **not checked**; add adversarial tests at these boundaries and document the host’s responsibility for tool permissions. [rag/openrouter_pipeline.py:277](../../../rag/openrouter_pipeline.py:277), [rag/server.py:314](../../../rag/server.py:314), [rag/contextual_retrieval.py:35](../../../rag/contextual_retrieval.py:35)

8. **P1 — Repair and run release acceptance against the artifacts.** The install script expects a keyless BM25 **answer**, whereas synthesis with retrieved passages requires an OpenRouter key; it also expects a JSON notice that the CLI does not emit. The listed CI instead uses simulated hosted providers and does not run the npm acceptance script. Align the tests with the intended behavior, then test the clean wheel, npm launcher and MCP call. [tests/install/smoke.sh:42](../../../tests/install/smoke.sh:42), [rag/openrouter_pipeline.py:202](../../../rag/openrouter_pipeline.py:202), [rag/cli.py:975](../../../rag/cli.py:975), [package verification:35](../../../docs/audits/2026-09-22-readiness/verify_package.py:35)

9. **P2 — Correct the published first-run instructions.** The README says bare `rag` opens the menu; the code and its test say it prints help. Update the instructions and remove or qualify Studio/demo claims for this release. [README.md:55](../../../README.md:55), [rag/cli.py:375](../../../rag/cli.py:375), [tests/test_cli.py:13](../../../tests/test_cli.py:13)
