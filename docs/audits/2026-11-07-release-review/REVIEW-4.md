# rag-mcp release review

## Verdict

**The CLI and MCP server are not ready to publish.** The new hidden-path filter rejects the default workspace store during ordinary searches, and file-scoped work fails when Git is unavailable. A configured endpoint override can also send a saved embedding key to a different provider. These are release risks, not just missing hardening. [Workspace default](../../../rag/workspaces.py:26), [scope filter](../../../rag/server.py:927), [Git check](../../../rag/server.py:875), [credential merge](../../../rag/settings.py:201).

**The sampled engineering is not yet on par with DeepSeek harness.** rag-mcp now gates publication on quality and installed-artifact jobs, but those jobs miss the default workspace regression and run on Linux alone. Its MCP response boundary generally accepts any JSON object, while the reference uses constrained protocol models and defines native release targets across Linux, macOS and Windows. [rag release](../../../.github/workflows/release.yml:55), [rag response validation](../../../rag/server.py:249), [reference models](deepseek-harness/python/sdk/src/deepseek_harness/models.py:35), [reference targets](deepseek-harness/.github/workflows/build-exe-for-python-sdk.yml:103).

## Earlier blockers

1. **Credentials — partly.** Key setting validates before saving and separates the dedicated OpenRouter key. But overriding only `RAG_MCP_EMBED_BASE_URL` retains the saved embedding key, which the embedder can send to the new endpoint. [Key command](../../../rag/keys.py:86), [merge](../../../rag/settings.py:201), [embedder](../../../rag/embeddings.py:331).
2. **Reconnect — partly.** Replacement preserves supported restrictions or refuses entries it cannot safely reconstruct. If both replacement and restoration fail, however, the old entry is gone. [Replacement](../../../rag/cli_agents.py:79), [Codex preservation](../../../rag/cli_agents.py:155).
3. **Changed ignore rules — fixed in source for the reported cases.** Cache signatures include ignore files and the Git index; failed checks raise instead of being cached as an empty result. The corresponding tests were **not run**. [Implementation](../../../rag/server.py:823), [tests](../../../tests/integration/test_ignore_changes.py:110).
4. **Studio-free distribution — fixed in source.** The build permits an absent bundle, and the artifact check rejects one in the release. A clean build was **not checked**. [Build hook](../../../hatch_build.py:15), [artifact check](../../../scripts/check_release_artifacts.py:23).
5. **MCP trust boundary — partly.** Trusted-client and shared-workspace limits are documented, but direct path queries retain a check/read race, and the new filtering breaks normal workspace searches. [Trust statement](../../../README.md:372), [query path](../../../rag/server.py:1072), [file read](../../../rag/parsers/text.py:14).
6. **Network behavior — partly.** Hosted processing is disclosed and offline flags are passed to FastEmbed. The offline tests replace FastEmbed with mocks; enforcement across the permitted dependency versions was **not checked**. [Disclosure](../../../README.md:29), [wrapper](../../../rag/embeddings.py:82), [test](../../../tests/unit/test_fastembed_offline.py:9).
7. **Prompt injection — partly.** The documentation assigns untrusted-content handling to the host. The adversarial test checks prompt placement while supplying a benign model response; real model and host behavior was **not checked**. [Trust statement](../../../README.md:378), [test](../../../tests/unit/test_prompt_injection_boundaries.py:9).
8. **Release acceptance — partly.** Publication now depends on quality and exact-artifact smoke jobs. The gated smoke does not establish semantic retrieval or a successful answer through the installed entry point; CI results and installations were **not checked**. [Release dependencies](../../../.github/workflows/release.yml:94), [smoke](../../../tests/install/smoke.sh:34), [separate answer probe](../../../docs/audits/2026-09-22-readiness/verify_package.py:35).
9. **First-run instructions — fixed.** The README says bare `rag` prints help and discloses the answer key and Studio-free package. [README](../../../README.md:25), [CLI test](../../../tests/test_cli.py:13).

## Problems introduced by the fixes

1. **P1 — Default workspace searches fail.** The default store is under `~/.local/state`; workspace searches pass its document directory to the new hidden-component filter, which rejects it for ordinary working directories. The installed smoke overrides the store with a non-hidden temporary path. A configured allowed root can also reject the store, despite the documented shared-workspace exception. [Default](../../../rag/workspaces.py:26), [execution](../../../rag/execution.py:210), [filter](../../../rag/server.py:927), [smoke setup](../../../tests/install/smoke.sh:15).
2. **P1 — Git became an undeclared runtime requirement.** For a nonempty file scope, failure to start `git check-ignore` now rejects the scope, including outside repositories. The quick start lists `uv` as the prerequisite. [Git failure](../../../rag/server.py:875), [file filter](../../../rag/server.py:934), [quick start](../../../README.md:25).
3. **P2 — Source import is platform-gated.** Every workspace import fails where `O_NOFOLLOW` or `O_DIRECTORY` is unavailable, despite OS-independent package metadata. Windows behavior was **not checked**. [Import](../../../rag/workspace_import.py:27), [metadata](../../../pyproject.toml:15).
4. **P2 — Allowed-root protection remains racy for direct queries.** Import uses a no-follow descriptor, but on-demand query validates a path and later opens it normally. A concurrent writer could swap a file between those steps; exploitation was **not checked**. [Validation](../../../rag/server.py:1072), [ingestion](../../../rag/ingestion.py:86), [reader](../../../rag/parsers/text.py:14).
5. **P2 — Failed reconnect recovery can still lose configuration.** After removal, a failed retry and failed restore leave only a warning; the failure test checks the warning, not preservation. [Reconnect](../../../rag/cli_agents.py:85), [test](../../../tests/unit/test_reconnect_safety.py:114).
6. **P2 — The added semantic smoke can pass on lexical search.** Its query and expected passage share words, and the mock-request assertion runs before the search. The accompanying test checks that search text appears in the script, rather than proving vector retrieval. [Smoke](../../../tests/install/smoke.sh:49), [fixture](../../../tests/install/facts.md:3), [script check](../../../tests/unit/test_release_workflow.py:60).

## Remaining gap to the reference

1. **Credential origins:** Bind saved keys to their provider endpoint and test the actual authorization header when endpoints and keys change. The reference tests credentials at the request boundary. [rag settings](../../../rag/settings.py:201), [reference test](deepseek-harness/packages/web/web-deepseek-api/tests/credentials.spec.ts:38).
2. **Platform and default-path coverage:** Exercise the installed CLI and MCP server with default stores, without Git, and on supported operating systems; otherwise narrow support claims. The reference defines native platform targets. [rag CI](../../../.github/workflows/python-quality.yml:12), [reference targets](deepseek-harness/.github/workflows/build-exe-for-python-sdk.yml:103).
3. **Release-shaped behavior:** Gate publication on a lexical miss followed by a semantic hit and a successful mocked answer through the exact installed artifacts. The reference gates validation on installed SDK and MCP scenarios. [rag smoke](../../../tests/install/smoke.sh:34), [reference release](deepseek-harness/.github/workflows/python-release.yml:68).
4. **Protocol responses:** Validate each tool’s result shape, not just that it is an object; retain request-schema checks. The reference defines constrained protocol models. [rag response boundary](../../../rag/server.py:249), [reference models](deepseek-harness/python/sdk/src/deepseek_harness/models.py:35).
5. **Safe diagnostics:** Sanitize embedding-probe exceptions before returning them through MCP; the settings path currently forwards exception text. Add stable error categories and recovery guidance. [Probe error](../../../rag/settings.py:397), [MCP response](../../../rag/server.py:674), [reference error types](deepseek-harness/python/sdk/src/deepseek_harness/errors.py:4).
6. **Shared-host isolation, if required:** Add per-agent workspace authorization and tests when clients need different authority. The current trust statement permits shared workspace access; the reference tests scoped resource visibility. [rag trust boundary](../../../README.md:372), [reference scope test](deepseek-harness/packages/mcp/mcp-resources/tests/resources.spec.ts:167).

The review used file inspection and small in-memory probes; **the test suite was not run**. CI outcomes, clean builds and installations, real providers and MCP hosts, other operating systems, and live race or injection exploits were **not checked**. No files were changed.
